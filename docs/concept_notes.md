# 신용리스크 핵심 개념 정리

작성일: 2026-11-24 (1주차)
목적: 프로젝트에 필요한 신용리스크 개념을 본인 말로 설명할 수 있도록 정리한다.

## 1. 신용리스크와 기대손실

신용리스크는 차주가 약속한 원리금을 갚지 못해 은행이 손실을 입을 위험이다. 은행은 손실을 세 요소로 나누어 계산한다.

| 요소 | 의미 | 예시 |
|---|---|---|
| PD | 일정 기간(보통 1년) 안에 부도날 확률 | 2% |
| LGD | 부도 시점의 노출 금액 중 회수하지 못하는 비율 (LGD = 1 − 회수율) | 50% |
| EAD | 부도 시점의 노출 금액 (대출 잔액 + 앞으로 인출될 한도분) | 2,000만 원 |

```
EL = PD × LGD × EAD
   = 0.02 × 0.5 × 20,000,000 = 200,000원
```

### 유도
부도 사건을 D라 하면, 손실은 부도가 나지 않으면 0이고 부도가 나면 LGD × EAD이다. 기댓값은 다음과 같다.

```
E[손실] = P(D) × E[LGD × EAD | D]
```

LGD와 EAD를 고정값으로 보면 EL = PD × LGD × EAD가 된다. 이는 세 요소가 서로 독립이라는 단순화이며, 실제로는 불황기에 PD와 LGD가 함께 오르는 상관이 있다.

### EAD와 LGD의 구분 (헷갈렸던 부분)

```
부도 시점의 노출 (EAD)           2,000만 원
 ├─ 부도 후 회수 (회수율 50%)    1,000만 원  (담보 처분, 채권 매각, 추심 등)
 └─ 미회수 (LGD 50%)             1,000만 원  → 실제 손실
```

- LGD 50%는 "이미 50%를 갚았다"가 아니라 "부도 후 노출 금액의 약 50%가 회수된다"는 뜻이다.
- 1,000만 원은 EAD가 아니라 LGD를 적용한 결과(부도 시 손실액)다. EAD에 1,000만 원을 넣고 LGD를 또 곱하면 회수를 두 번 반영하게 된다.
  - 맞는 계산: 0.02 × 0.5 × 2,000만 = 20만 원
  - 이중 반영: 0.02 × 0.5 × 1,000만 = 10만 원
- 부도 이전의 상환은 EAD를 줄이고, 부도 이후의 회수는 LGD로 반영한다. 예를 들어 2,000만 원 중 400만 원을 갚은 뒤 부도가 났다면 EAD는 1,600만 원이다.
- LGD는 개별 건의 확정값이 아니라 평균적인 추정값이며, 회수에 드는 비용과 시간이 길수록 높아진다.

### EL의 쓰임새
- 충당금 산정 (IFRS 9의 기대신용손실도 PD·LGD·EAD를 사용)
- 대출 금리에 평균 손실분을 반영
- 승인 여부와 한도 판단
- 예상보다 큰 손실(UL)은 EL이 아니라 자기자본으로 대비하며, 이 부분이 바젤 규제와 연결된다.

## 2. 바젤 규제

바젤은행감독위원회가 정하는 은행 자기자본 규제의 국제 기준이다. 은행은 위험을 안고 있는 만큼 자본을 쌓아 두어야 한다.

- 바젤 I (1988): 신용리스크 중심, 위험가중자산 대비 최소 자본비율 8% 도입
- 바젤 II (2004): 최소자본, 감독당국 검토, 시장규율의 세 축으로 확장하고 은행의 자체 모형 사용을 허용
- 바젤 III (2008 금융위기 이후): 자본의 질과 양 강화, 레버리지 비율과 유동성 규제 추가

### 내부등급법(IRB)과 이 프로젝트의 위치
- 기초 IRB: 은행이 PD를 추정하고 LGD, EAD는 감독당국 기준을 사용
- 고급 IRB: PD, LGD, EAD를 모두 은행이 추정
- 이 프로젝트의 PD 모형은 **내부등급법의 PD 추정 단계**에 해당한다. (면접에서는 "바젤 II"보다 "내부등급법의 PD 추정"까지 말한다.)

## 3. 스코어카드

신청자의 특성을 구간별 점수로 바꾸고 합산해 부도 위험을 순위화하는 방식이다. 점수가 어떻게 나왔는지 설명할 수 있어 은행이 선호한다.

- 신청 스코어카드: 대출 신청자의 승인 여부 판단 (이 프로젝트)
- 행동 스코어카드: 기존 고객의 이후 연체 가능성 관리

### 구성 순서
```
변수 구간화(binning) → WoE 변환 → IV로 변수 선택 → 로지스틱 회귀 → 점수 변환
```

### WoE
```
WoE_i = ln( (구간 i의 Good 수 / 전체 Good 수) / (구간 i의 Bad 수 / 전체 Bad 수) )
```
- 이 정의에서 양수는 안전한 구간, 음수는 위험한 구간이다.
- 라이브러리에 따라 분자·분모가 반대인 정의를 쓸 수 있으므로 **도구를 쓸 때 부호 정의를 먼저 확인한다.**

### IV
```
IV = Σ_i ( Good비율_i − Bad비율_i ) × WoE_i
```

| IV | 해석 |
|---|---|
| 0.02 미만 | 예측력 거의 없음 |
| 0.02 ~ 0.1 | 약함 |
| 0.1 ~ 0.3 | 중간 |
| 0.3 ~ 0.5 | 강함 |
| 0.5 초과 | 너무 좋음, 누수 의심 |

IV가 비정상적으로 높으면 가장 먼저 대출 시점에 알 수 없는 정보가 들어갔는지(누수)를 확인한다. 구간을 지나치게 잘게 나눴는지, 특정 구간의 표본이 너무 적은지도 함께 본다.

### 로지스틱 회귀
```
ln( p / (1 − p) ) = β0 + β1·WoE_1 + β2·WoE_2 + ...
```
p/(1−p)는 오즈(odds)이며, 오즈의 로그가 변수들의 선형결합이므로 각 변수의 기여도를 해석하기 쉽다.

### 점수 변환 (7주차에 상세 정리)
```
Score = Offset + Factor × ln(odds)
Factor = PDO / ln(2)
```
- PDO(Points to Double the Odds): 오즈가 2배가 될 때 오르는 점수
- 유도: 오즈가 2배인 두 점수의 차이는 Factor × ln(2) = PDO이므로 Factor = PDO / ln(2)
- **확인 필요(7주차):** 점수는 보통 Good:Bad 오즈 기준으로 만든다. 모형이 Bad 확률을 예측하도록 학습했다면 점수 변환 시 부호를 맞춰야 한다.

## 4. 이 프로젝트의 범위

- 중심은 PD 모형(스코어카드, 평가지표, cut-off 분석)
- LGD와 EAD는 기대손실 개념 연결 수준 (의사결정 기록 D-003 참고)
