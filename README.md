# Lending Club 기반 은행 개인 대출 신용리스크 분석

대출 신청자의 부도 가능성을 예측하고, 이를 승인·거절 기준(cut-off)과 연결해 해석하는 신용리스크 분석 프로젝트입니다. 신용평가 모형(스코어카드)을 구축하고, 비교 모델과 성능·안정성 지표로 검증합니다.

> 진행 상태: 진행 중 (2026.11 ~ 2027.02, 1인 프로젝트)

## 1. 프로젝트 배경과 목표

- 은행은 대출 심사 시 신청자의 부도 가능성(PD)을 추정해 승인 여부와 한도·금리를 결정합니다.
- 이 프로젝트는 은행 개인 대출 심사 상황을 가정하고, 아래 과정을 처음부터 끝까지 수행하는 것을 목표로 합니다.
  1. 부실(부도) 정의 설계
  2. 변수 처리와 위험 요인 분석 (WoE/IV)
  3. 로지스틱 회귀 기반 스코어카드와 비교 모델 구축
  4. 성능 평가 (AUC, KS, Gini)와 안정성 점검 (PSI)
  5. cut-off별 승인율·부실률 trade-off 해석
